# FitApp Admin Dashboard 🚀
FitApp mobil uygulaması için geliştirilmiş, modern ve "glassmorphism" tasarım diline sahip yönetim panelidir. Antrenman programlarını, hareketleri, kullanıcıları ve genel istatistikleri kolayca yönetmenizi sağlar.
## 🌟 Özellikler
- **🔒 Güvenli Yönetim:** Modern tasarımlı ve güvenli Admin Portal girişi.
- **👥 Global Kullanıcı Yönetimi:** Tüm sayfalarda geçerli, header üzerinden kontrol edilen kullanıcı seçimi ve senkronizasyonu.
- **🏋️ Program & Hareket Havuzu:** Antrenman programlarını oluşturma, düzenleme ve "Sürükle & Bırak" (Drag & Drop) ile kolayca sıralama.
- **📊 Gelişmiş Analitikler:** Kullanıcı bazlı ve genel sistem istatistikleri, vücut ölçüleri takibi.
- **📥 CSV İçe Aktarma:** Bodybuilding.com ve FitnessProgramer.com formatlarında toplu hareket ekleme desteği.
- **🎨 Modern Arayüz:** Koyu tema (Dark Mode), Lucide ikonları ve Tailwind CSS ile geliştirilmiş şık kullanıcı deneyimi.
## 🛠️ Teknolojiler
- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Dil:** TypeScript
- **Stil & Tasarım:** Tailwind CSS
- **İkonlar:** Lucide React
## 🚀 Kurulum ve Çalıştırma
Projeyi yerel ortamınızda çalıştırmak için:
1. Bağımlılıkları yükleyin:
   ```bash
   npm install
   ```
2. Geliştirme sunucusunu başlatın:
   ```bash
   npm run dev
   ```
3. Tarayıcınızda [http://localhost:3000](http://localhost:3000) adresine gidin.
## 📦 Yayına Alma (Deployment)
Bu proje [Vercel](https://vercel.com/) üzerinde yayınlanmaya tam uyumludur. Güncellemeleri canlıya almak için terminalinizden şu komutları kullanabilirsiniz:
```bash
git add -A
git commit -m "Proje güncellemeleri"
git push
```
